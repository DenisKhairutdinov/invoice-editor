# Редактор счетов

Статическое приложение для фирменного оформления счетов 1С в браузере. Поддерживает PDF и DOCX до 20 МБ и 30 страниц, предпросмотр A4 и скачивание PDF, JPEG или DOCX.

## Запуск

Требуется Node.js 24 LTS версии 24.16 или новее и npm. В папке проекта выполните:

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Astro.

## Работа со счётом

1. Нажмите на пустой лист в предпросмотре или перетащите на него PDF или DOCX. Для DOCX проверьте страницы в предпросмотре, поскольку браузер может разметить документ иначе, чем Word.
2. Выберите баннер по миниатюре или добавьте свой PNG/JPEG кнопкой «Загрузить». Иконка перечёркнутого изображения отключает баннер. Баннер и подвал выравниваются по видимому содержимому каждой страницы. Высота баннера рассчитывается по пропорциям изображения. Без баннера верхнее поле составляет 10 мм, если позволяет высота счёта.
3. Откройте «Реквизиты подвала». По умолчанию заполнены данные ООО «Энергомаш», включая телефон `+7 (904) 808-18-04` и почту `1@bik55.ru`. Реквизиты и QR выровнены по низу. В панели настроек по умолчанию задан размер текста 9 pt и размер QR 24 мм. Адрес сайта и QR-кода — `https://bik55.ru/`.
4. Проверьте каждую страницу. Стрелки переключают страницы. Масштаб 100% вписывает лист в область предпросмотра. Масштаб меняется ползунком или колёсиком над предпросмотром. Увеличенный лист можно перемещать, удерживая левую кнопку мыши. Если оформление занимает слишком много места, редактор показывает исходные страницы и блокирует скачивание. Можно отключить баннер или подвал.
5. Выберите формат рядом с кнопкой «Скачать». PDF сохраняет векторное тело исходного PDF в масштабе 1:1. JPEG имеет 2480 × 3508 пикселей и 300 DPI, для нескольких страниц скачивается ZIP. Word содержит изображения страниц и предназначен для просмотра и печати.
6. «Сбросить настройки» возвращает исходные значения, «Закрыть счёт» освобождает рабочую область.

Настройки сохраняются в LocalStorage, пользовательские баннеры — в IndexedDB текущего браузера. Один открытый счёт сохраняется в приватном файловом хранилище браузера (OPFS) для восстановления после перезагрузки. «Закрыть счёт» удаляет копию, успешно открытый новый счёт заменяет её. Если браузер запрещает доступ к хранилищу, редактор сообщает об этом. Обработка выполняется на устройстве после загрузки файлов приложения.

На узком экране кнопка со значком настроек переключает предпросмотр и панель редактирования.

## Подготовка к публикации

Встроенные баннеры берутся из `assets/banners/`. Добавляйте только изображения, рассчитанные на публичное распространение. Счета и конфиденциальные материалы храните отдельно от репозитория.

```sh
npm run check
npm run lint
npm run lint:styles
npm run format:check
npm test
npx playwright install chromium
npm run test:e2e
npm audit
npm run build
```

Playwright сам собирает отдельную копию под `/invoice-editor/`, поднимает локальный Astro preview и генерирует синтетические счета. Для проверки Chrome и Edge укажите `INVOICE_BROWSER_CHANNELS=chrome,msedge`. Переменная `INVOICE_YANDEX_PATH` позволяет запустить проверки в установленном Яндекс Браузере. Для ручного production-предпросмотра сборки с префиксом задайте `BASE_PATH=/invoice-editor/` при сборке и запуске `npm run preview`.

Для репозитория [DenisKhairutdinov/invoice-editor](https://github.com/DenisKhairutdinov/invoice-editor) в настройках Pages выберите GitHub Actions. Workflow проверяет код и историю Git, запускает тесты, собирает статический сайт с base path Pages и публикует `dist` из `main`. Первая публикация требует приёмки.

## Ограничения

- Границы видимого содержания PDF определяются по рендеру с запасом. На новых формах 1С проверьте тонкие линии и светлые печати. PDF с поворотом, аннотациями, полями, слоями, профилем печати или нестандартным UserUnit отклоняется. Используйте плоский PDF из 1С. Цифровые подписи исходного PDF в оформленный файл не переносятся.
- DOCX с внешними связями, активными вложениями или неподдерживаемыми изображениями отклоняется. Автоматическая пагинация зависит от разметки Word. Для длинной таблицы, которую браузер не может надёжно разбить на страницы, используйте PDF из 1С.
- Интерфейс остаётся функциональным прототипом.

Результаты проверки и границы приёмки приведены в [docs/STATUS.md](docs/STATUS.md).
